TableFlow

网页表格导出助手

在 Microsoft Edge 中选择网页表格，先预览，再复制到 Excel 或导出 CSV。适用于常见网页表格与数据网格；数据范围取决于当前页面实际可读取的内容。

发现与预览

用户主动点击扩展，查看检测结果、行列数量和部分数据预览。

复制与导出

复制 Excel 兼容数据，或生成支持中文、逗号、引号和换行的 CSV。

范围与风险提示

区分当前页与仅可见数据；发现缺失风险时，提醒用户检查再导出。

网页数据在浏览器本地处理

当前扩展没有业务服务器、账号、analytics 或广告跟踪。用户使用时会读取完成导出所必需的网页内容，表格内容不会上传给 TableFlow。

隐私政策 / Privacy Policy

Web table export, with a preview first

TableFlow helps Microsoft Edge users copy common web tables to Excel or export CSV. It warns when the detected data may be incomplete. Page data is processed locally, with no TableFlow business server, accounts, analytics, or advertising tracking.
