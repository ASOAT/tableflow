# 推广图规格与内容建议

核对日期：2026-10-06。[微软 Edge 发布指南](https://learn.microsoft.com/en-us/microsoft-edge/extensions/publish/publish-extension)列明：Small promotional tile 为 440×280；Large promotional tile 为 1400×560 PNG。每种语言最多一张相应图，均为可选。

小图：TableFlow 名称、自有表格/导出图标、短句“网页表格，复制到 Excel”。大图：名称与短句“先看范围，再导出”，配真实选表预览或缺失风险提醒的局部截图。

使用与扩展图标一致的深蓝和青绿，优先清晰文字与简单表格图形。不使用 Microsoft/Excel 商标图标、不声称全网站支持，不放用户业务数据。本阶段交付规格和设计说明，未生成或审核正式推广 PNG。
