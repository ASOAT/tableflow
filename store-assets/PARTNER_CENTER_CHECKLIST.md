# Partner Center submission checklist

所有项目由发布者在 Microsoft Partner Center 中真实操作和复核。此清单没有表示已登录、已上传或已提交；自动化不会勾选这些项目。只有人工 QA 全部通过后，才使用 `npm run release:final` 生成的正式 ZIP。

- [ ] 待人工完成 — Microsoft Edge Developer account verified / Microsoft Edge Developer account 已验证
- [ ] 待人工完成 — Account type checked: Individual / 本人核对账号类型为 Individual
- [ ] 待人工完成 — Publisher display name checked: Asoat / 本人核对发布者显示名称为 `Asoat`
- [ ] 待人工完成 — Publisher rights confirmed / 本人确认拥有 TableFlow 代码、名称和素材的发布权
- [ ] 待人工完成 — Microsoft developer account contact email checked / 本人核对 Microsoft 开发者账户联系邮箱真实有效；用于账户和商店管理，不要求在隐私页或商店文案中公开
- [ ] 待人工完成 — Public support entry checked / 本人核对公共支持入口为 [TableFlow GitHub Issues](https://github.com/ASOAT/tableflow/issues)；公共支持可以使用此 URL，无需公开私人邮箱
- [ ] 待人工完成 — Privacy URL added / 真实 HTTPS 隐私政策 URL 已匿名验证
- [ ] 待人工完成 — Markets reviewed / 发布市场
- [ ] 待人工完成 — Visibility reviewed / 可见性
- [ ] 待人工完成 — Chinese listing added / 中文介绍
- [ ] 待人工完成 — English listing added / 英文介绍
- [ ] 待人工完成 — Logo uploaded / 300×300 PNG 商店 Logo
- [ ] 待人工完成 — Screenshots uploaded / 已审核正式截图
- [ ] 待人工完成 — Search terms added / 每语言不超过 7 项、21 words、单项 30 字符，核对表单计数
- [ ] 待人工完成 — Certification notes added / 审核说明
- [ ] 待人工完成 — Package uploaded / 正式 ZIP，不能误传 RC 或测试副本
- [ ] 待人工完成 — Privacy disclosures answered truthfully / 如实说明主动读取当前页、本地处理、必要本地偏好及可选网站权限
- [ ] 待人工完成 — Final preview reviewed / 最终商店预览、联系入口和语言素材
- [ ] 待人工完成 — Submit clicked / 人工确认后提交审核

GitHub Issues 是公开渠道。反馈问题、隐私询问和兼容性报告时，不应提交敏感表格内容、个人信息、账号密码、Token、Cookie 或完整业务数据。此支持入口不代替 Microsoft 开发者账户中的真实联系信息。

参考：[Microsoft Edge 发布指南](https://learn.microsoft.com/en-us/microsoft-edge/extensions/publish/publish-extension)。实际字段以提交当天 Partner Center 表单为准。
